Kinematik des Zylinders

FeldTypBedeutung
kinematics.typecrank_sliderAktuell einzige Kinematik im classic-Pfad.
bore_mfloat > 0Bohrung.
stroke_mfloat > 0Hub.
conrod_mfloat > 0Pleuellänge.
compression_ratiofloat > 1Geometrisches Verdichtungsverhältnis.
phase_degfloatPhasenversatz je Zylinder.
Der klassische Pfad kennt aktuell keine Kurbelwellen-ODE. speed_rpm ist eine Eingabe, kein Ergebnis. Für reale Drehzahldynamik braucht es eine zusätzliche Rotationsgleichung und ein Trägheitsmodell.

Vollständiges Minimalbeispiel classic

modeling:
  architecture: classic

preprocessing:
  gas_properties:
    cp_J_per_kgK: 1005.0
    cv_J_per_kgK: 718.0
    R_J_per_kgK: 287.0
  features:
    mass_flow: true
    wall_heat: false
    combustion: false
    evaporation: false
    pv_work: true
  engine:
    cycle_type: 4t
    speed_rpm: 3000.0
  volumes:
    - name: cyl_1
      type: cylinder
      initial_pressure_Pa: 101325.0
      initial_temperature_K: 300.0
      kinematics:
        type: crank_slider
        bore_m: 0.08
        stroke_m: 0.08
        conrod_m: 0.13
        compression_ratio: 10.0
        phase_deg: 0.0
      wall_heat: {model: none}
      combustion: {model: none}
      evaporation: {model: none}
    - name: intake
      type: environment
      pressure_Pa: 101325.0
      temperature_K: 300.0
    - name: exhaust
      type: environment
      pressure_Pa: 101325.0
      temperature_K: 900.0
  connections: []

simulation:
  dt_s: 1e-5
  total_cycles: 4
  save_last_cycles: 1
  solver: {kind: rk4, rtol: 1e-6, atol: 1e-9}

postprocessing:
  csv_enabled: true
  csv_path: results/out.csv
  csv_separator: ";"
  excel_enabled: false
  excel_path: results/out.xlsx
  sampling: {mode: crank_angle, step_deg: 1.0}
