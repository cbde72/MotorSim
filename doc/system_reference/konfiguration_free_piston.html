FeldTyp/OptionenBedeutung
typebounce_chamberBounce-Volumentyp.
modelgas_spring | gas_exchangeGeschlossen oder topologisch angebunden.
initial_pressure_Pa, initial_temperature_KfloatStartzustand der Bounce.
chamber_diameter_m, chamber_length_m, compression_rationeuer GeometriewegEmpfohlen.

Bei model: gas_exchange darf die Bounce-Kammer über orifice und check_valve topologisch angebunden werden. Bei gas_spring muss sie geschlossen bleiben.

Connections im free_piston-Pfad

  • valve ist aktuell nicht zulässig.
  • slot ist zulässig, aber nur mit opening_mode: by_distance.
  • Bounce-Volumes dürfen aktuell nur über orifice oder check_valve angebunden werden, wenn model: gas_exchange gesetzt ist.
Connection-TypWesentliche FelderHinweis
valveopening_angle_deg, opening_reference, profile_angle_domain, lift_scale, lash_m, lift_file, alpha_k_fileIm free_piston-Pfad aktuell nicht erlaubt.
slotopening_mode, distance_from_tdc_m oder opening_angle_deg, width_m, height_m, number_of_identical_holes, discharge_coefficientsIm free_piston-Pfad nur by_distance.
orificearea_m2, forward_cd, reverse_cdEinfacher Drosselpfad.
check_valvearea_m2, discharge_coefficient, cracking_pressure_PaEinwegventil.

Vollständiges Minimalbeispiel free_piston

modeling:
  architecture: free_piston

free_piston:
  initial_conditions:
    x0_m: 0.05
    v0_m_per_s: 0.0
    cylinder:
      pressure_Pa: 120000.0
      temperature_K: 300.0
    combustion_state:
      burned_fraction_0to1: 0.0
      released_energy_J: 0.0
      ignition_armed: false
      injection_armed: false
  mechanics:
    moving_mass_kg: 0.7
    piston_diameter_m: 0.0605
    compression_ratio: 30.0
    x_min_m: 0.0
    x_max_m: 0.108
  friction:
    model: coulomb_viscous
    fc_N: 40.0
    cv_Ns_per_m: 0.0
  load:
    model: viscous
    damping_Ns_per_m: 0.0

preprocessing:
  gas_properties:
    cp_J_per_kgK: 1005.0
    cv_J_per_kgK: 718.0
    R_J_per_kgK: 287.0
  features:
    mass_flow: true
    wall_heat: false
    combustion: true
    evaporation: false
    pv_work: true
  engine:
    cycle_type: 2t
    speed_rpm: 25.0
  volumes:
    - name: cylinder
      type: cylinder
      initial_pressure_Pa: 120000.0
      initial_temperature_K: 300.0
      kinematics:
        type: crank_slider
        bore_m: 0.0745
        stroke_m: 0.08
        conrod_m: 0.12
        compression_ratio: 30.0
        phase_deg: 0.0
      wall_heat: {model: none}
      combustion:
        model: vibe
        start_mode: compression_hub
        start_hub_m: 0.05
        duration_hub_m: 0.01
        a: 6.9
        m: 2.0
        added_energy_per_cycle_J: 500.0
        energy_coupling: none
      evaporation: {model: none}
    - name: bounce
      type: bounce_chamber
      model: gas_exchange
      initial_pressure_Pa: 300000.0
      initial_temperature_K: 300.0
      chamber_diameter_m: 0.07
      chamber_length_m: 0.108
      compression_ratio: 16.0
      polytropic_exponent: 1.3
  connections: []

simulation:
  dt_s: 1e-5
  total_cycles: 1
  save_last_cycles: 1
  simulationtime: 0.2
  solver: {kind: rk4, rtol: 1e-6, atol: 1e-9}

postprocessing:
  csv_enabled: true
  csv_path: results/free_piston.csv
  csv_separator: ";"
  excel_enabled: false
  excel_path: results/free_piston.xlsx
  sampling: {mode: time, step_s: 1e-4}
