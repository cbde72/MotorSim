# Projektdaten

Dieses Verzeichnis enthält die zu den Beispielkonfigurationen gehörenden Tabellen-Dateien:

- `intake_valve_lift.csv`
- `exhaust_valve_lift.csv`
- `intake_alpha_k.csv`
- `exhaust_alpha_k.csv`
- `slot_cd_table.csv`

Hinweis:
- Die `alpha_k`-Dateien verwenden absichtlich eine Lift-Achse in `mm`, damit die automatische mm→m-Erkennung im Loader und in der GUI-Vorschau greift.
- Die Ventilhubdateien verwenden ebenfalls `mm` im Header.
